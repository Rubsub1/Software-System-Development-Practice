本目录用于提交数据模型、小数据输入和独立人工预期。完整投档模块开发前先完成人工推演，不能根据程序输出反推预期。

## 提交清单

- [ ] ER 图、表结构、字段说明、主外键和约束。
- [ ] 控制线、梯度参数及数据库初始化方案。
- [ ] 小数据集：学校、计划、考生、资格和志愿；必要时用多个场景覆盖四批。
- [ ] 逐批次、逐梯度、逐志愿的人工推演过程。
- [ ] 预期录取名单、投档顺序、各计划余额及结转明细。
- [ ] 数据接口、输入版本和名额守恒设计说明。
