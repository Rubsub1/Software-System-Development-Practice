# 阶段四 测试与交付

本目录用于提交测试对照、规模模拟和最终交付材料。测试结论必须与真实运行结果一致。

## 提交清单

- [ ] 小数据人工预期与实际输出对照；记录输入、预期、实际结果及结论。
- [ ] 可执行测试或脚本：覆盖梯度、志愿顺序、分数边界、资格、同分、跨批排除、初中名额隔离、结转与异常输入。
- [ ] 数据一致性与复现测试：录取唯一、不超额、名额守恒、结转一次、统计一致和同版本重跑。
- [ ] 两个高分滑档案例及志愿调整前后的完整运行对照，包括输入、人工推演和落选原因。
- [ ] 15 万名虚构考生规模模拟：记录随机种子、生成配置、运行环境、数据分布、耗时、内存和结果核对；如未完成，注明实际规模和限制。
- [ ] Docker 部署与使用说明：依赖、配置、初始化、启动、样例数据、持久化、操作流程与已知限制。
- [ ] 设计报告、实际分工与贡献记录、AI 使用说明，以及完整投档和至少两个易错边界的演示材料。
